# pfinance docs

The user-facing documentation site — the fork-and-host guide, the
environment-variable reference, and the optional CI pipeline. Built with
[Starlight](https://starlight.astro.build) and deployed alongside the app by
the Alchemy stack (`Docs` in `alchemy.run.ts`).

## Structure

Pages live in `src/content/docs/`; each file is a route named after its path.
The sidebar is configured in `astro.config.mjs`, except `reference/`, which is
autogenerated from the directory.

| Page                                 | Covers                                                      |
| ------------------------------------ | ----------------------------------------------------------- |
| `guides/quickstart.md`               | Fresh Cloudflare account → deployed, claimed instance       |
| `reference/environment-variables.md` | Every deployer-facing variable, its default, and its effect |
| `guides/ci-pipeline.md`              | The optional GitHub Actions pipeline and PR previews        |

These pages present the deploy defaults recorded in `docs/fork-deploy.md`;
when a default or knob changes, update both.

## Commands

Run from the repository root:

```sh
vp run --filter docs dev     # dev server
vp run --filter docs build   # production build to ./dist (runs in CI)
```
